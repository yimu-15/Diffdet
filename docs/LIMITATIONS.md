# 局限与已知问题（LIMITATIONS）

## 方法局限

1. **非迭代扩散**：DiffDet 是 diffusion-inspired 的单次前向特征去噪，不包含 DDPM 的
   时间步/噪声调度/反向采样。它不具备迭代扩散模型"逐步精修"的能力，重雾（β=3.0）
   下的增益有限。
2. **只修复 C5**：仅对最高层 C5 特征去噪，C2~C4 的低层雾噪声未处理；多尺度去噪是否
   更优未验证。
3. **合成雾假设**：VOC-FOG 采用统一大气散射模型（均匀大气光 + 指数深度衰减），与真实
   雾天的非均匀雾、眩光等存在分布偏移，跨域泛化未评估。
4. **蒸馏/量化增益未严格证明**：学生 U-Net 相对教师的精度、INT8 的精度保持均依赖
   具体 checkpoint，未做跨 seed 稳定性分析。

## 实验/复现局限

1. **消融表 0.8369/0.8342/0.8342 无法复算**（见 `experiments/RESULT_AUDIT.md` §3）。
   本仓库可复现的最终结果为 0.7835（与主实验一致）。
2. **无跨 seed 结果**：主实验与消融均为单次运行，未报告均值±方差。
3. **INT8 仅为 W8A32 模拟**：未在真实推理引擎（TensorRT/ONNX Runtime）上验证，不声称
   INT8 算子加速或真实速度提升。
4. **效率测量**：FPS/显存为单卡前向基准（`tools/benchmark.py`），不含完整数据加载与
   NMS 之外的自定义后处理；baseline 17.7 vs DiffDet 18.5 的 +0.8 FPS 属测量噪声范围。
5. **数据/权重**：未随库分发 VOC 数据与大体量权重，完整复现需合法获取数据并自行训练。
